# Minimal dark edition 1.6

The latest user direction restores dark styling and supersedes the paper design. Two main areas: left navigation and the calendar canvas. Uniform charcoal background, subtle grid, solid muted category fills, rounded event blocks and readable white type. No wallpaper, metadata rail, hatching or heavy event outlines.

Calendar indicators are reduced to dates and deadline counts. Issues remain available through the toolbar; walking calculations still affect planning while travel labels are hidden. Review appears beneath the calendar only when a proposal exists, in a collapsible section. Task completion checkboxes, full-day Agenda, date navigation, search and mobile tools are retained. The interface defaults to dark even if a prior version stored a light preference.

Colour describes category. Completed sessions have a check; missed sessions say Missed; proposed sessions use a plus and a quiet inset edge. Every event still opens full details. Small events and overlapping events may truncate; Day view provides more room.
